Plateful

Les recettes de la famille, notées par toute la famille.

iPhone : installez l’app Plateful (avec son icône, sans Expo Go)
  1. Installez TestFlight (l’app gratuite d’Apple pour les apps privées).
  2. Sur l’iPhone, touchez ce bouton, puis Accepter et Installer :
Rejoindre Plateful sur TestFlight Ouvrez Plateful depuis son icône, entrez le code JTYYZJ et votre prénom. Si le lien dit « n’accepte pas de testeurs », Apple n’a pas encore validé la première version (moins d’un jour) : réessayez plus tard, ou utilisez Expo Go en attendant.
Android : installez l’app Plateful (avec son icône, sans Expo Go) Télécharger Plateful pour Android
  1. Ouvrez le fichier téléchargé (110 Mo).
  2. Si Android demande, touchez Paramètres et autorisez l’installation depuis Chrome, puis revenez et touchez Installer.
  3. Ouvrez Plateful, entrez le code JTYYZJ et votre prénom.
En attendant, avec Expo Go — 1. Acceptez l’invitation (une seule fois)
  1. Ouvrez le courriel d’Expo intitulé « invited to join rarau ».
  2. Touchez Accept, puis Continue with Google avec votre adresse Gmail.
Pas de courriel ? Regardez dans Promotions ou Pourriels, ou demandez à Luca.
2. Installez Expo Go (gratuit) et connectez-vous :
App Store (iPhone) Google Play (Android)
  1. Dans Expo Go, touchez l’icône du compte en haut à droite.
  2. Touchez Log in, puis Continue with Google avec la même adresse Gmail.
3. Ouvrez Plateful — sur le téléphone, touchez ce bouton : Ouvrir Plateful dans Expo Go Depuis un ordinateur : scannez ce code avec l’appareil photo du téléphone.
4. Entrez le code famille, puis touchez votre prénom ou tapez-le :
JTYYZJ
La prochaine fois : ouvrez Expo Go, Plateful est dans « Récemment ouvert ».
