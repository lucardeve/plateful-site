Plateful

Les recettes de la famille, notées par toute la famille.

1. Ouvrez Plateful sur votre téléphone. Rien à installer, pas de compte. Ouvrir Plateful Depuis un ordinateur : scannez ce code avec l’appareil photo du téléphone.
2. Entrez le code famille, puis touchez votre prénom ou tapez-le :
JTYYZJ
3. Mettez-la sur l’écran d’accueil, comme une vraie app :

iPhone (Safari)
Touchez le bouton Partager (le carré avec une flèche), puis « Sur l’écran d’accueil », puis Ajouter.

Android (Chrome)
Touchez le menu ⋮, puis « Ajouter à l’écran d’accueil » ou « Installer l’application ».

Ensuite, ouvrez Plateful depuis son icône verte. Vous restez connecté.
